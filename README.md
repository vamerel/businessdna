# Plugins van VA-Merel

Deze marketplace bevat drie plugins:

| Plugin | Wat | Installeren in |
|---|---|---|
| `businessdna` | Business DNA: zeven skills die je merk-DNA vastleggen in Notion | Chat & Cowork |
| `content-studio` | Claude Content Studio: haakjes, captions, ideeën bewaren, automatisch publiceren | Chat & Cowork |
| `content-designsystem` | De skill `@designsystem` voor Claude Content Studio | **alleen** Claude Code |

De installatie-instructies en de uitleg vind je in de leeromgeving van de training.

## Kort

- Voeg in de Claude-app de marketplace `vamerel/claude-plugins` toe en installeer de plugins
  die bij je training horen.
- Zet automatisch synchroniseren aan, dan krijg je nieuwe versies vanzelf.
- Installeer `content-designsystem` alleen in Claude Code.

## Voor de beheerder

Deze repo wordt gevuld door `publiceer-marketplace.ps1` vanuit de bronmappen. Pas hier niets
met de hand aan in `plugins/`: de volgende publicatie overschrijft het.
